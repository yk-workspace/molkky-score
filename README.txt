# モルック スコアボード PWA

GitHub Pages用のPWA構成です。

## ファイル
- index.html
- manifest.json
- sw.js

## GitHub Pages
この3ファイルを同じ階層に配置し、GitHub Pagesを有効化してください。

## Android
1. ChromeでGitHub PagesのURLを開く
2. ページを一度読み込む
3. Chromeメニューから「ホーム画面に追加」または「アプリをインストール」
4. ホーム画面から「モルック」を起動

※既に以前のショートカットを作成している場合は、一度削除してから再追加してください。
